    播放源与备份

    播放源

    搜索网址里用 {q} 代表片名；网址里没有 {q} 的，点击时会自动复制片名，到站内搜索框粘贴。在对应网站搜一次，把地址栏里的片名换成 {q} 贴进来即可。影片下面只显示能直接打开播放页的来源；搜索网址只在“记录播放网址”里用来帮你找到播放页。

    自动保存到 GITHUB

    填入访问令牌后，标记会自动保存到你的私有仓库，换浏览器或清了缓存也能找回。令牌只存在这个浏览器里。

    备份

    没有登录时，标记只存在这台设备的这个浏览器里。换设备或清理浏览器数据前，把下面的备份文字存好；在新设备上粘贴后点“导入”。
